OpenFactory 收藏助手

连接你的 OpenFactory 站点，一键把 GitHub / Gitee 仓库收进「我的仓库」。

1. 连接站点

2. 授予页面访问权限

扩展只在点击收藏时读取当前仓库页的标题、简介与 Star 数，不会上传其他内容。 首次连接站点时需要授予该站点的访问权限。

使用方式

  1. 打开任意 GitHub / Gitee 仓库页面。
  2. 点击工具栏中的扩展图标，或按 Ctrl + Shift + O。
  3. 在弹窗中确认仓库信息，点击「收藏到 OpenFactory」。

收藏成功后可在站点「我的仓库」中查看；重复收藏会更新描述、语言与 Star 数。

断开连接

清除本机保存的 API 地址与令牌，不会影响服务端已生成的令牌。
